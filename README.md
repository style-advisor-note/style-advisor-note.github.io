# スタイルノート

パーソナルカラー・骨格診断・顔タイプ診断・メイクレッスンの結果を、毎日の服選び・メイク・買い物に使うための個人用Webアプリです。

- 早見表: 自分の診断ルール（似合う色・形・素材など）を1画面で確認
- メイク: レッスンで習った手順をステップごとのカードで確認し、仕上がりをチェック
- 判定: 服やコスメを、診断ルールで ◎○△× 判定（ルール判定／Claude による写真判定）

## しくみ
- `index.html` 1ファイルで動く静的サイトです（GitHub Pages で公開）
- 診断データ・APIキー・判定の履歴は、使う人の端末の中（localStorage / IndexedDB）にだけ保存します。このリポジトリには含まれません
- 写真判定のときだけ、写真と診断データを Anthropic の Claude API に送ります

## 使い方
1. 設定で診断データ（profile.json）を読み込む
2. 写真判定を使う場合は、設定で Claude の APIキーを保存する
